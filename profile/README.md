# Praxia Atelier

**We build agentic operating systems for real businesses.**

AI Agents · Vertical SaaS · Workflow Automation · Decision Systems · Multi-model AI

Praxia connects data, processes, AI models, agents and tools into one operating system, so a business can act on what happens (an email, a request, a document) with AI doing the groundwork and people keeping control of the decisions that matter.

> One architecture. Multiple operating environments.

### How we build

- **AI proposes, people decide.** Every action has an autonomy level: automatic, approval required, or manual only.
- **Code computes the numbers.** Models interpret; deterministic logic calculates and validates.
- **Provider-independent.** Workflows name tasks, not model vendors.
- **Audited by default,** without storing personal data in the logs.
